Linux Kernel Tracing with eBPF & BCC

2-hour hands-on session on tracing syscalls, disk I/O, and kernel bottlenecks with eBPF and BCC.

When
24 Nov 2026 · 19:00–21:00 UTC+7
Where
Online
Quota
30 seats
Price
Free

Overview

Learn to inspect live Linux kernels safely in production using BCC and bpftrace—no custom kernel modules required.

Syllabus

  1. 19:00–19:30 UTC+7 eBPF architecture, verifier safety model, and tracepoints vs kprobes.
  2. 19:30–20:30 UTC+7 Hands-on BCC & bpftrace: tracing syscalls, page cache misses, and block I/O latency.
  3. 20:30–21:00 UTC+7 Reading flamegraphs, production safety checklist, and Q&A.

Prerequisites

  • Comfortable using a Linux shell (bash/zsh)
  • Basic understanding of processes, filesystems, and TCP/IP

Mentor

Radova Core Team · Systems engineers maintaining hardened Linux infrastructure and archival storage tooling.
