Linux Kernel Tracing with eBPF & BCC

Practical workshop on tracing syscalls, I/O latency, and kernel bottlenecks using eBPF and BCC tools.

When
2026-11-24 · 19:00–21:00 WIB
Where
Online
Quota
30 seats
Price
Free

Overview

Learn how to inspect live Linux kernel behavior safely in production without kernel modules or heavy profiling overhead. We walk through real-world syscall, disk I/O, and TCP latency diagnostics using BCC and bpftrace.

Syllabus

  1. 19:00–19:30 WIB (UTC+7) eBPF architecture, verifier safety model, and tracepoints vs kprobes.
  2. 19:30–20:30 WIB (UTC+7) Hands-on BCC & bpftrace: tracing syscalls, page cache misses, and block I/O latency.
  3. 20:30–21:00 WIB (UTC+7) Reading flamegraphs, production safety checklist, and Q&A.

Prerequisites

  • Comfortable using a Linux shell (bash/zsh)
  • Basic understanding of processes, filesystems, and TCP/IP

Mentor

Radova Core Team · Systems engineers maintaining hardened Linux infrastructure and archival storage tooling.
